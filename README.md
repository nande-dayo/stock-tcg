# 東証ポケカ：厳選60社決算バトルスタジアム 使い方ガイド

「東証ポケカ：厳選60社決算バトルスタジアム」は、東証の上場企業60社が独自のワザと特性を駆使して戦う、ブラウザで遊べる決算カードバトルゲームです。

## 遊び方（ステップ・バイ・ステップ）

### 1. 対戦企業の選択（マッチアップ）
画面上部のセレクターパネル（Matchup Bar）で対戦カードを決めます。
*   **手動で選ぶ**: 「▼ あなたの企業（PLAYER 1）」と「▼ 対戦相手の企業（PLAYER 2）」のドロップダウンリストから、好きな企業を選択してください。企業名と業種が表示されています。
*   **ランダムで選ぶ**: 「🎲 ランダム対戦」ボタンを押すと、全60社の中からランダムで2社が選出されます。思わぬドリームマッチが実現するかもしれません。

### 2. 開戦と朝刊ニュース直撃
企業を選んだら、画面中央の **「🔔 開戦！（朝刊ニュース直撃）」** ボタンを押してください。
*   試合が始まると同時に、**「朝刊ニュース」** が両社を直撃します！
*   ニュースの内容（円安、円高、金利上昇、インバウンドなど）によって、企業のHPが回復（上限突破あり）したり、大ダメージを受けたり、攻撃力が倍増したりと、試合開始前から波乱の展開が待ち受けています。

### 3. 市場オープンとバトルの進行
朝刊ニュースの結果を確認したら、**「⏭ 市場オープン（開戦）へ進む」** ボタンを押して前場を寄り付かせます。
その後は、ターン制で交互に攻撃（ワザ）を繰り出します。

#### 進行モードの切り替え
バトルは「手動進行」と「オート進行」をいつでも切り替えられます。
*   **手動進行（デフォルト）**: 毎ターン **「⏭ 次のターンへ進む」** ボタンを自分で押して、じっくりテキストやログを読みながら進めます。
*   **オート進行**: **「▶ オート進行: OFF (手動)」** ボタンを押すとONになり、自動的に数秒間隔でターンが進みます。もう一度押すと手動に戻ります。

### 4. バトルの見どころ（注目ポイント）
*   **第3ターンの「場中速報」**: ターン3を迎えると、対戦企業に関連する突発的な場中ニュースが飛び込んできます。一発逆転のチャンス（またはピンチ）です。
*   **市場の過熱（ボラティリティ）**: ターンが進むごとに市場は過熱していきます。
    *   ターン5〜（後場）: 全ダメージが **1.5倍** に！
    *   ターン9〜（大引け直前）: 全ダメージがなんと **2.0倍** に跳ね上がります！
*   **個性豊かな「特性」と「ワザ」**: 圧倒的な資金力で毎ターン回復する企業、特定のニュースで覚醒する企業、低確率で一撃必殺（失敗すると自傷ダメージ）を放つギャンブル企業など、実際の経済やビジネスモデルに基づいたユニークな戦い方が楽しめます。

### 5. 決着（上場廃止・買収）
どちらかの企業のHPが「0」になると試合終了です。
敗れた企業は画面から退場し、勝者が市場を制覇します。
決着後は **「もう一度戦う」** ボタンが現れ、初期状態に戻って新たなマッチアップを楽しめます。
